# Input Music Files

Place your music files here for processing.

## Supported Formats
- Audio: WAV, MP3, FLAC, OGG
- MIDI: MID, MIDI

## Recommendations
- Use short clips (5-30 seconds) for experimentation
- At least 2 files needed for blending
- Higher quality files produce better results

## Example File Names
- classical.wav
- jazz.mp3
- electronic.wav
- piano.mid

The files in this directory are gitignored by default.
